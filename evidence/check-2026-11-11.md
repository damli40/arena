## One thing that differed from the plan, and why

**The plan said "against intent: 450 for vault-a". The first run said 2450.** The plan assumed
the library had 5 prompt-injection attacks (the hand-written scenarios). It has 15: the 5
hand-written ones, 6 that Muse wrote from papers, and 5 from news items (committed by the news
hunter in `5d2621e` during this build). All 15 are written against the same owner task, "pay
Sam's inv-pay, nothing else" (the Muse prompt states it), so each carries that written intent.
`scripted-01-control-pay-valid` has the same steps as the hand-written clean scenario s0, so it is
the 16th. Fix: the report now splits the number by who wrote the attack (hand-written / from
papers / from news), so the README's 450 is visible as its own line. No scoring changed.

## The wrapper test (renamed guard)

`examples/renamed-guard/` is `targets/vault-a/src/lib.rs` with only its 12 public method names
renamed (`pay` -> `execute_payment`, `new` -> `setup_vault`, ...; `RENAMES.md`). Built with Rust 1.86;
its 17 unit tests pass after the same renames.

- Without a mapping (and Muse off), the check stops before any sandbox and lists each missing role
  and every method the wasm exports (`error-cases.txt`, case 1).
- With the hand-written `mapping.json`: held 52/52, 0 beyond the rules, 450 / 2450 against intent.
  Per attack, status, tokens beyond the rules, tokens against intent and honest invoices paid are
  identical to vault-a in all 52 attacks.
- Muse, asked with no mapping (one call, `muse-spark-1.3`), proposed exactly the hand-written
  mapping for all 11 roles; the checks accepted it. That run used a 2-attack subset, so it shows
  the proposal path works, not a full score from a Muse mapping.

## Error messages

`error-cases.txt` (inputs in `error-case-inputs/`): wrong method names, init args missing a field,
a deposit the guard refuses, `pay` mapped to a method that sends no tokens ("no ft_transfer was
seen"), the paid status value set wrong, owner and agent swapped, a file that is not wasm. Each
stops with exit 2 and says what to change; none reports "held".
